# Пространственный Терминал (Dimension Terminal)

Блок с голографическим экраном, светящийся с яркостью 12. Открывает Cover Flow интерфейс для быстрой телепортации между измерениями.

## Получение

**Рецепт крафта:**
- Кусочки крионита (по углам и краям)
- Глаз Эндера (центр)
- Обсидиан (оставшиеся слоты)

## Интерфейс (Cover Flow UI)

При ПКМ по терминалу открывается экран с каруселью карточек измерений.

### Навигация

| Действие | Управление |
|----------|------------|
| Листать карточки | Колесо мыши, стрелки ←→, A, D |
| Выбрать карточку | Клик по карте |
| Телепортироваться | Enter, Space, клик по выбранной карте, кнопка «ТЕЛЕПОРТАЦИЯ» |
| Навигация краями | Стрелки ◀▶ по краям экрана |

### Визуальные эффекты

- **3D-поворот карт** вокруг оси Y (карусель Cover Flow)
- **Неоновая рамка** цветом измерения: золото (майндинг), голубой (Overworld), оранжевый (Незер), фиолетовый (Энд)
- **Пульсация** центральной карточки
- **Баннер карты измерения** — текстура в стиле Jappa (64×64)
- **Иконки руд** измерения под названием
- **Зеркальное отражение** на глянцевом полу
- **Инерция скролла** с плавным затуханием (ease-out)

## Телепортация

1. Сервер ищет безопасную точку приземления (блок с тремя блоками воздуха над ним)
2. Если безопасная точка не найдена — строит 3×3 обсидиановую платформу на поверхности
3. При первом посещении шахтёрского измерения рядом ставится ответный терминал для обратного телепорта

## Безопасность

- Телепортация происходит только на безопасные поверхности
- Лава и воздух под ногами исключены
- Платформа из обсидиана строится при необходимости
